# 📈 Number of Orders Prediction

A Machine Learning project that predicts food order demand using historical data.

## 🚀 Features

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Linear Regression
- LightGBM Regressor
- Model evaluation
- Data visualization

---

## 🛠️ Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- LightGBM
- Plotly
- Matplotlib

---

## 📊 Models Used

- Linear Regression
- LightGBM

---

## 📈 Evaluation Metrics

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
